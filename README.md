## Repository Structure

- **Short & structured:** Well-organized into topic folders and numbered files for sequential reading.
- **Wordings & definitions preserved:** Core concepts, method signatures, ASCII diagrams, and explanations are kept intact.
- **Clean format:** Clean, readable Markdown without distracting icons or emojis.
- **Quick revision tables:** Consolidated cheat sheets and comparison matrices in every module.

---

## How to Navigate

1. Navigate to any topic folder (e.g. `Exception Handling/` or `Java Web/`).
2. Open `README.md` inside that folder for the topic index.
3. Read notes in numbered order (`01-...`, `02-...`).
4. Review the final quick revision note in each module for rapid preparation.
